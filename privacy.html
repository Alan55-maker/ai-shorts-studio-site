AI Shorts Studio 隱私權政策 / Privacy Policy

最後更新 / Last updated: 2026-11-20

1. 使用者 / Who uses it

AI Shorts Studio 是個人自用的桌面工具，只由開發者本人使用，用來管理自己擁有的 YouTube 頻道。

AI Shorts Studio is a personal desktop tool used only by its developer to manage the developer's own YouTube channels.

2. 存取的 Google 資料 / Google data accessed

  • youtube.upload：上傳本人製作的影片到本人的頻道，並設定標題、說明與排程。
    Uploading the owner's videos to the owner's channels with title, description and schedule.
  • youtube.readonly：讀取本人頻道已上傳 / 已排程的影片清單，用來安排發布時間。
    Reading the owner's own uploaded / scheduled videos to plan publishing times.

3. 資料的儲存與分享 / Storage and sharing

  • 授權權杖（token）與影片資料只存在使用者自己的電腦上，不會傳送到任何其他伺服器。
    Authorization tokens and video data are stored only on the owner's own computer and are not sent to any other server.
  • 不收集、不出售、不分享任何個人資料給第三方，也不用於廣告。
    No personal data is collected, sold, shared with third parties, or used for advertising.
  • 本工具對 Google 使用者資料的使用遵守 Google API 服務使用者資料政策（包含有限使用規定）。
    Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 撤銷授權 / Revoking access

隨時可以到 Google 帳戶的第三方存取權 移除 AI Shorts Studio 的存取權， 並刪除電腦上的權杖檔案。
Access can be revoked at any time at myaccount.google.com/permissions.

5. 聯絡 / Contact

請透過 OAuth 同意畫面上顯示的支援電子郵件聯絡。
Please use the support email shown on the OAuth consent screen.
